## 🛠️ Step-by-Step Recording Instructions

### 1. Recommended Free Recording Tools (No Watermark, 1080p)
- **OBS Studio (Recommended):** Download free from [obsproject.com](https://obsproject.com/). Add Source $\rightarrow$ Window Capture (choose your browser window). Set Output to 1080p 60fps.
- **Loom (Browser Extension / Desktop):** Free up to 5 minutes, records screen + camera bubble simultaneously.
- **Windows Built-in Game Bar:** Press `Win + Alt + R` to start/stop recording any active application.

### 2. Pre-Recording Checklist
- [ ] Open Chrome at [https://nexusclear.web.app](https://nexusclear.web.app) in Full Screen (`F11` or maximize).
- [ ] Set browser zoom to 100% or 110% for crisp readability.
- [ ] Close all other tabs, bookmarks bar (`Ctrl + Shift + B`), and disable notifications.
- [ ] Test your microphone level (ensure no echo or fan background noise).
- [ ] Do a 30-second dry run following Part 3 (Scenario 1 submit $\rightarrow$ approve).

### 3. Timing Rule
- **Minimum Duration:** 3 minutes 00 seconds (180 seconds).
- **Maximum Duration:** 3 minutes 55 seconds (235 seconds).
- **DO NOT EXCEED 4 MINUTES** to avoid automatic disqualification or penalties.

### 4. Upload & Submission Checklist
- [ ] Upload video to **YouTube** as **"Unlisted"** (or Loom / Google Drive with access set to *"Anyone with the link can view"*).
- [ ] Test the link in an **Incognito / Private browser window** to ensure judges can watch it without login prompts.
